# Mio's Fraction Lab

A fractions practice app for iPad. Everything runs in the browser, and progress is saved on the device only.

- `index.html` is the whole app.
- `manifest.webmanifest` and `icons/` let it install to the Home Screen like a real app.
- `sw.js` lets it work offline.

To update the app, replace `index.html` and push. The iPad picks up the new version the next time it opens the app while online.
