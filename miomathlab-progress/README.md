# Mio's Math Lab: progress (private)

Mio's learning data for the weekly update. Keep this repo private.

- `inbox/`: drop this week's progress code (paste into a .txt file), worksheet photos, and notes here.
- `snapshots/`: one decoded progress file per week, added by the weekly update.
- `PROGRESS.md`: the long-term report, rewritten each week; old weeks are never deleted.
